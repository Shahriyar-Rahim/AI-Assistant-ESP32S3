# Implementation status

Status definitions:

- `NOT_STARTED`: no functional implementation exists.
- `IN_PROGRESS`: some functionality exists, but acceptance scope is incomplete.
- `IMPLEMENTED`: functional implementation exists; requested verification is incomplete or externally dependent.
- `TESTED`: the relevant automated/build verification passed. This does not imply live provider, physical hardware, or production verification.
- `BLOCKED_EXTERNAL_DEPENDENCY`: verification or completion requires explicitly named hardware, credentials, approval, model assets, or external infrastructure.

The project is incomplete. Every row below is intentionally scoped to the named capability, not inferred from a related build.
